# 🧠 Disease Prediction Toolkit

A machine learning–based toolkit that predicts the likelihood of diabetes using patient health data.  
This project demonstrates a complete ML workflow including data preprocessing, model training, evaluation, and result analysis.

---

## 📌 Project Overview

Early detection of diseases like diabetes can significantly improve patient outcomes.  
This project uses the **Pima Indians Diabetes Dataset** to build and evaluate machine learning models that predict whether a patient is diabetic based on medical attributes.

---

## 📊 Dataset

- **Name:** Pima Indians Diabetes Dataset  
- **Source:** Kaggle  
- **Features include:**
  - Pregnancies
  - Glucose level
  - Blood Pressure
  - Skin Thickness
  - Insulin
  - BMI
  - Diabetes Pedigree Function
  - Age
- **Target Variable:** Outcome (0 = Non-Diabetic, 1 = Diabetic)
